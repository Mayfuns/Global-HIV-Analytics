# Global HIV Dashboard

This folder contains the three Power BI report pages used in the Global HIV Analytics project.

## Dashboard pages

1. **Global HIV Overview** — people living with HIV, new infections, HIV-related deaths, ART coverage, mortality and survival.
2. **Geographic HIV Burden** — country and regional comparisons of HIV burden, infections and deaths.
3. **Treatment Access & HIV Outcomes** — ART coverage, mortality burden, survival and country-level treatment outcomes.
